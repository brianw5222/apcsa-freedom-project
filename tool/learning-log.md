### 10/3/24:
*
Flask is a web framework for Python that makes it easy to build web applications.
Installed Flask using pip install flask.
Learned how to create a basic Flask app and run it locally on my computer.
Flask uses routes to define different parts of a web app (e.g., home page, about page).
https://flask.palletsprojects.com/

### 10/21/24:
*
Flask routes map URLs to Python functions (views).
Used @app.route() to link URLs to functions.
Created two simple pages: home and about.


### 11/4/24:
*
Flask uses Jinja2 templates to display HTML dynamically.
Used render_template() to link HTML files with Python code.
Learned how to pass variables from Python to HTML (e.g., {{ variable }}).


### 11/12/24:
*
Flask allows users to submit forms through POST requests.
Created a simple form with HTML and handled form data in Python.
Used request.form to access form data.
https://python-adv-web-apps.readthedocs.io/en/latest/flask.html

### 11/25/24:
*
request object lets you get data from the user's browser (e.g., form data).
response object allows you to send data back to the browser.
Used redirect() to send users to different pages.


### 12/9/24:
*
url_for() helps you create URLs for specific routes in your app.
This is helpful when you want to avoid hardcoding URLs in your templates.
